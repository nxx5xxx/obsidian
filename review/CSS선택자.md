# 선택자
스타일을 적용할 HTML 요소를 지정하는 패턴

## 기본선택자
### 전체 선택자
**\*** 로 나타낸다

예시 :
```
* {
 color:black;
}
```

### 태그선택자
특정 태그이름을 가진 요소를 선택

예시
```
span {
	color:red;
}
```

### ID선택자
\# 로 지정한다
예시
```
#sp1 {
	color:blue;
}
---
<span id="sp1">
 sp1예시
</span>
```

### class선택자
\. 로 지정한다
예시
```
.cl1 {
	color:blue;
}

---
<span class="cl1">
	cl1예시
</span>
```

## 결합자
Combinators라고 한다
### 자식결합자
E > F 부모요소 E 바로 아래의 자식요소 F를 선택한다.

### 자손결합자
E F
E 하위에 포함된 모든 F 요소(후손)를 선택한다

### 인접 형제 결합자
E + F
E 바로뒤에 나오는 형제요소 F를 선택한다

### 일반현제 결합자
E ~ F
E 뒤에 나오는 모든형제요소 F를 선택한다

## 가상 클래스 및 가상 요소
### 가상 클래스
\: 요소의 특정한 상태를 선택
예 : :hover , :active, :visited

### 가상요소
:: 요소의 특정 부분에 스타일을 적용한다
예 : ::before, ::after,
