###### 동적타이핑
#동적타이핑
**예시**
정적타이핑
```
int number = 5;
```
동적타이핑
```
def number = 10
str = "Hi"
```
최상단과 같이 타입을 미리 지정해주고 해당하는 타입만 가능한것이 정적타이핑
두번째 예시와 같이 변수명에 정의만 해준고 실행시 타입이 지정되는것이 동적 타이핑이다
장점으로는 코드가 간결해지고 작성속도가 빠르고 단점으로는 타이핑실수가 컴파일 시 걸러지지않고 프로그램 실행중에 오류가 발생할 수 있다는것

##### 주요 활용처
찾아보니 Gradle에 쓰이는게 맞다 Gradle 빌드 스크립트 작성에 사용된다
Grails 프레임 워크에서도 사용된다고 한다
자동화 및 테스트에 사용된다고 한다 이유로는 빠른 스크립팅과 프로토타이핑에 유용함
