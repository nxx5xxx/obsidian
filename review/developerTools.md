인텔리제이엔 설명이 써있으니까 해당 설명들을 써놔보겠다

## GraalVM Native Support
GraalVM의 native-image컴파일러를 사용하여 Spring 어플리케이션 네이티브 실행파일로 컴파일 할수 있도록 지원 이라고 써있다
검색해보니 자바코드를 미리 컴파일 하여 JVM 없이도 즉시 실행할 수 있게 만드는 기술
이라 써있다

자세한사항은
https://docs.oracle.com/ko/learn/graalvm-and-containerisation/index.html#introduction
를 참고

## GraphQL DGS Code Generation
스키마파일을 파싱(분석)해서 데이터 타입과 안전한타입의 API를 생성하고 GraphQL API를 조회할수 있도록 한다. 라고 써있으며
넷플릭스의 DGS(Domain Graph Service) 프레임워크와 Code Generation 기능을 사용하면 GraphQL API를 안전하고 빠르게 개발 할 수 있습니다
라고 써있다

## Spring Boot DevTools
애플리케이션 빠른재시작, 라이브리로드, 향상된 개발경험 구성을 제공한다
라고 간략하게 써있으며
코드를 고치고 저장하면 서버를 재시작하지 않아도 자동으로 새로고침 해주는 도구라고 생각하면 된다

## Lombok
반복적으로 재사용되는 코드를 간결하게 나타내도록 도와주는 Java Annotaion 라이브러리 이다
@Getter, @Setter, @ToString, @NoArgsConstructor등으로 줄여준다

## Spring Configuration Processor
개발자가 사용자 정의 설정 키를 사용할 때, 상황에 맞는 도움말과 코드 자동완성을 제공할 수 있도록 메타데이터를 생성하는 기능

## Docker compose Support
향상된 개발경험을 위해 도커구성 지원을 공급하다 라고 써있는데 너무 애매해서 찾아봤다
- 스프링 부트 애플리케이션이 시작될 때 compose.yml 등을 감지해 자동으로 도커 컨테이너를 실행하고 애플리케이션이 종료되면 컨테이너도 함께 정지된다
- 수동으로 application.properties에 접속 URL,사용자이름,비밀번호 등을 적지 않아도 스프링 부트가 컨테이너포트와 설정 정보를 파악해 데이터소스를 자동으로 설정한다
- 동적포트지원 기본적으로 호스트 포트를 충돌없이 동적으로 할당하여 여러개의 스프링부트 프로젝트를 동시에 띄울때에도 포트충돌을 막아준다

## Srping Modulith
모놀리식 구조에서 모듈 간의 의존성을 깨지 않도록 코드를 검증하고 문서화하는 아키텍처 도구입니다.
라 써있는데... 전혀 감이 안온다
GPT에게 도움받아보자면 아래와 같이 설명되어있다

모놀리식 애플리케이션 안에서 명확한 모듈 경계를 설정하고 검증할 수 있도록 돕는 스프링 공식 프로젝트입니다.

- **모듈 구조화:** 패키지 단위로 논리적인 모듈을 정의하고 `@ApplicationModule` 등의 어노테이션으로 모듈을 선언합니다.
- **의존성 규칙 검증:** 모듈 간의 순환 참조나 허용되지 않은 패키지 접근을 테스트 코드로 자동 검증합니다.
- **이벤트 기반 통신:** 모듈 간 결합도를 낮추기 위해 도메인 이벤트 발행 및 리스너 처리를 쉽게 구현할 수 있도록 지원합니다.
- **문서화 지원:** 정의된 모듈 구조와 상호작용을 바탕으로 아키텍처 다이어그램(PlantUML 등)을 자동으로 생성해 줍니다.
