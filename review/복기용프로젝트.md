# SQL선택
OracleSQL과 MySQL 그리고 PHP와 JAVA 어떤것을 먼저 할 까 선택하는 와중
MySQL 또는 MariaDB와 JAVA를 택하기로 했다.
이유는 일단 자바가 재밋고 OracleSQL 보다는 MySQL이 JPA사용시에 좀 더 유용했던걸로 기억하는게 첫번째고 - 사실 이 첫번째도 어떤부분에서 유용했는지 기억도 잘 안난다 안되면 될때까지 하는 성격때문에 잘 안착시켰다는 사실에서 힘들었던 기억 대부분 까먹음
두번째로는 MySQL Workbench가 너무 불편하여 HeidiSQL등으로 사용하였었는데
그 때문에 조금 다른 SQL문이 햇갈릴때가 있어 택했다.
