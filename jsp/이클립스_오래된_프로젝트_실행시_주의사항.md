
# Build Path 에러
```
Multiple annotations found at this line:

- The superclass "javax.servlet.http.HttpServlet" was not found on the Java Build Path
```

와 같이 Java Build Path에러는
해당 프로젝트 우측마우스 클릭 > ProperTies > Project Facets 에서 톰캣을 다시 설정해줘야한다.

# 환경변수 에러

환경변수를 해당 버전에 맞게끔 설정해줫는데도

```
java was started but returned exit code
```

와 같은 에러가 뜬다면
```
C:\Program Files (x86)\Common Files\Oracle\Java\javapath
```
와 같은 환경변수가 추가되어있나 확인한다
1.8버전과 11버전 두개를 설치 해 놓았기 때문에
수동으로 변경해야하는 상황이라면 위에것을 제거

eclipse.ini에서 Java경로 직접 지정할 수도있ㄷ
