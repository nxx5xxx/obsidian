
# Build Path 에러
```
Multiple annotations found at this line:

- The superclass "javax.servlet.http.HttpServlet" was not found on the Java Build Path
```

와 같이 Java Build Path에러는
해당 프로젝트 우측마우스 클릭 > ProperTies > Project Facets 에서 톰캣을 다시 설정해줘야한다.

# 환경변수 에러

환경변수를 해당 버전에 맞게끔 설정해줫는데도

```
java was started but returned exit code
```

와 같은 에러가 뜬다면
```
C:\Program Files (x86)\Common Files\Oracle\Java\javapath
```
와 같은 환경변수가 추가되어있나 확인한다
1.8버전과 11버전 두개를 설치 해 놓았기 때문에
수동으로 변경해야하는 상황이라면 위에것을 제거

eclipse.ini에서 Java경로 직접 지정할 수도있다
```
-vm
C:\Program Files\Java\jdk1.8.0_241\bin\javaw.exe

위의 두줄을 -vmargs 바로 위에 추가한다
```

이래도 에러가 뜬다면
해당 프로젝트의 .metadata 를 삭제해 초기화해준다


# Server.xml에러
```
Could not publish server configuration for Tomcat v8.0 Server at localhost.

Multiple Contexts have a path of "~~~~".
```
```
java.lang.IllegalArgumentException: The main resource set specified [.../wtpwebapps/~~~~~~] is not valid
```
서버를 실행했을 때 위와 같은 에러가 뜬다면

server.xml안에 똑같은 Path를 가진 프로젝트 설정이 중복으로 들어가서 발생하는 문제이다
중복된 Context를 정리해줘야한다
```
<Context docBase="~~~~" path="/~~~~" reloadable="true" source="..."/>
```
위와 같이 되어있다.
